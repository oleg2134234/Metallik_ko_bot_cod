# Установка клиентского бота на metallik.ru

Инструкция для администратора сайта «Металлик и Ко».

## 1. Что устанавливается

На страницы сайта добавляется плавающая кнопка «Написать нам». После нажатия посетителю доступны:

- диалог с ботом непосредственно на сайте;
- переход в Telegram;
- переход в WhatsApp;
- переход в MAX.

Обращения и контактные данные передаются в CRM. Административная панель CRM не встраивается в публичный сайт и остаётся доступной только сотрудникам.

## 2. Что получить у разработчика бота

До установки администратору должны передать:

1. Публичный адрес файла виджета, например `https://bot.example.ru/widget.js`.
2. Идентификатор сайта, например `metallik-ru`.
3. Публичный адрес API для создания диалогов и заявок.
4. Разрешённый домен: `https://metallik.ru` и, если используется, `https://www.metallik.ru`.
5. Ссылки на подключённые каналы Telegram, WhatsApp и MAX.
6. Контакт ответственного за отключение виджета при неисправности.

> Текущий адрес `metallik-crm.yarosh-oleg.chatgpt.site` является приватной админкой. Его нельзя использовать вместо публичного файла `widget.js`.

## 3. Рекомендуемый код установки

Код следует разместить перед закрывающим тегом `</body>`:

```html
<script>
  window.MetallikBotConfig = {
    siteId: "metallik-ru",
    apiUrl: "https://АДРЕС-СЕРВЕРА-БОТА/api",
    position: "right",
    channels: {
      website: true,
      telegram: "https://t.me/ИМЯ_БОТА",
      whatsapp: "https://wa.me/НОМЕР_В_МЕЖДУНАРОДНОМ_ФОРМАТЕ",
      max: "https://max.ru/АДРЕС_АККАУНТА"
    }
  };
</script>
<script src="https://АДРЕС-СЕРВЕРА-БОТА/widget.js" defer></script>
```

Значения, написанные заглавными буквами, необходимо заменить на данные, полученные от разработчика. Не публикуйте в этом коде пароли, токены Telegram, ключи WhatsApp или ключи CRM.

## 4. Установка в 1С-Битрикс

Перед изменениями сделайте резервную копию шаблона.

1. Войдите в административную часть сайта.
2. Откройте **Настройки → Настройки продукта → Сайты → Шаблоны сайтов**.
3. Определите шаблон, подключённый к `metallik.ru`.
4. Откройте файл `footer.php` активного шаблона.
5. Вставьте код из раздела 3 непосредственно перед `</body>`.
6. Сохраните изменения.
7. Очистите кеш: **Настройки → Настройки продукта → Автокеширование → Очистка файлов кеша**.
8. Откройте сайт в режиме инкогнито и выполните проверку из раздела 7.

Если сайт использует несколько шаблонов, код необходимо добавить в каждый публичный шаблон либо вынести в общий подключаемый файл.

## 5. Установка через Google Tag Manager

Этот вариант подходит, если контейнер GTM уже установлен на всех страницах.

1. Создайте тег **Пользовательский HTML**.
2. Вставьте код из раздела 3.
3. Выберите триггер **All Pages / Все страницы**.
4. Сохраните и запустите режим предварительного просмотра.
5. Проверьте работу на компьютере и телефоне.
6. Опубликуйте контейнер с понятным названием версии, например `Виджет клиентского бота`.

## 6. Настройка каналов

### Telegram

Для обычного перехода используется ссылка `https://t.me/имя_бота`. Для автоматического создания заявки нужен Telegram Bot Token. Токен хранится только на сервере бота.

### WhatsApp

Ссылка на диалог имеет вид `https://wa.me/79991234567`. Для автоматической обработки входящих и исходящих сообщений требуется официальный WhatsApp Business Platform либо подключённый официальный провайдер.

### MAX

Указывается публичная ссылка на аккаунт или бота MAX. Если требуется автоматическая переписка и получение ответов в CRM, разработчик должен отдельно подтвердить доступность API для используемого аккаунта.

### Чат на сайте

Чат должен передавать на сервер:

- страницу, с которой обратился клиент;
- имя и выбранный способ связи;
- телефон и/или e-mail;
- текст переписки;
- интересующий товар;
- согласие на обработку персональных данных;
- согласие на рассылку отдельным полем.

## 7. Проверка после установки

Проведите проверку с тестовым контактом:

1. Кнопка видна на главной странице, в каталоге и карточке товара.
2. Кнопка не закрывает меню, корзину и важные элементы на мобильном экране.
3. Открываются только настроенные каналы.
4. Сообщение из чата появляется в разделе «Диалоги» CRM.
5. Имя, телефон, e-mail, страница и выбранный товар попадают в карточку клиента.
6. Новый контакт не добавляется в массовую рассылку без отдельного согласия.
7. Ответ клиента на рассылку появляется в фильтре «Ответили».
8. Менеджер может перехватить диалог у бота.
9. После закрытия окна черновик не показывается другому посетителю.
10. В консоли браузера нет ошибок, связанных с `widget.js`, CORS или Content Security Policy.

## 8. Настройки безопасности

- Разрешить запросы API только с доменов `metallik.ru` и `www.metallik.ru`.
- Добавить ограничение частоты запросов и защиту от спама.
- Не хранить токены и пароли в HTML сайта.
- Передавать данные только по HTTPS.
- Ограничить доступ к админке сотрудниками компании.
- Записывать действия менеджеров и изменения массовых рассылок.
- Хранить согласие на обработку данных и согласие на рассылку раздельно.
- Добавить ссылку на политику обработки персональных данных рядом с формой контакта.

## 9. Как временно отключить бота

В 1С-Битрикс удалите или закомментируйте две строки `<script>` из `footer.php`, затем очистите кеш. В Google Tag Manager приостановите тег виджета и опубликуйте новую версию контейнера. Это отключает клиентскую кнопку, но не удаляет уже сохранённые заявки и переписку из CRM.

## 10. Данные, которые нужно передать для запуска

- доступ администратора 1С-Битрикс или контакт администратора сайта;
- Telegram: имя бота и серверный токен;
- WhatsApp: рабочий номер и данные официального API/провайдера;
- MAX: публичная ссылка и данные API, если они доступны;
- название существующей CRM и доступ к её API;
- почтовый сервис для рассылок;
- утверждённые тексты согласий и ссылка на политику персональных данных;
- список сотрудников, которым разрешён вход в административную панель.
